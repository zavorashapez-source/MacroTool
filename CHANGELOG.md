# Changelog

## v1.3

**New**
- Main page: your keyboard, mouse and controller with brand, model and how they're connected, and which macro sits on which key. Hover a key to see its macro, click it to edit
- Live view: keys, mouse buttons and controller buttons light up on the picture when you press them
- Controller support: controller buttons can trigger macros. Set a macro's key and press the button. Xbox pads work right away, PlayStation and Switch pads through Steam Input or DS4Windows
- Controller picture for Xbox, PlayStation and Switch layouts, with sticks, triggers and battery level

**Good to know**
- The game still gets controller presses, they can't be blocked like keyboard keys

## v1.2

**New**
- Pull Out macro (Settings > Extras): swaps back to your weapon after you finish an edit. Works with all Editing macros, Drag Edit included
- New {Weapon} bind under Game keybinds, set it to the key you pull your weapon out with (default 2)

## v1.1

**New**
- In-game menu: press Insert in game, click macros on/off right over Fortnite. Insert or Esc closes it and you're back in the game (needs borderless/windowed)
- Edit / reset on release: if you have it on in Fortnite, turn on the same switch in Settings > General and edit macros stop pressing the extra confirm
- Edit Fix: if you get stuck in edit it taps your reset key by itself (colour check in the middle of the screen), plus Key check which spaces out edit spam so it can't jam (Settings > Edit Fix, needs borderless)
- Setup codes: share all your macros with one code (Profiles > Copy my setup / Import code). Single macro codes still work
- Quick insert chips in the editor: click {Edit}, LButton, down, wait 50... instead of typing
- Shortcuts: Ctrl+N new macro, Ctrl+F search, Ctrl+S save, Ctrl+Enter save steps, Esc close
- Welcome splash on startup
- Animations toggle (Settings > General), keeps animations on even when Windows has them turned off
- New tweaks
  - FPS: visual effects best performance, transparency off, mouse shadow and trails off, GPU priority high, bigger system cache, SysMain off for the game
  - Input: sticky / filter / toggle keys off, instant key repeat
  - Ping: free the 20% reserved QoS bandwidth, auto-tuning scale off
  - Cleanup: clear GPU shader cache, clear prefetch, empty recycle bin, close background apps

**Improved**
- New look: darker layered theme, brighter accent, cards with more depth, chart glow
- Smoother animations everywhere: buttons bounce a bit on press, lists and sections roll in, no stutter on any FPS
- Frame better timing is the default now

**Changed**
- "Drag Edit (Confirm on Release)" merged into Drag Edit, your old setup moves over by itself with the same key
- Code and readme cleanup
