**MACRO TOOL is free now** 🎉

No key, no paywall. It's a macro tool for Fortnite written in C++, one exe, about 1 MB, no DLLs.

**What's in it**
- Main page: your keyboard, mouse and controller, and which macro is on which key
- controller support: controller buttons can trigger macros
- macro engine on low-level hooks with its own high priority thread
- ready made macros: Single Edit, Drag Edit, Edit Reset, Edit Spam, Wall + Edit Peek and more
- macro editor with syntax colours, quick insert buttons, recorder, repeat/toggle
- in-game menu: press Insert in game and click macros on/off right over Fortnite (borderless/windowed)
- edit / reset on release: one switch and all edit macros match your Fortnite setting
- frame timing (Frame better adds a bit of jitter so taps always register)
- Edit Fix: auto reset when you get stuck in edit + anti spam throttle
- profiles, and you can share your whole setup with one code (MTP1:...)
- light/dark theme

**This is not a cheat.** It only sends the keys/mouse clicks you set up yourself. No aimbot, no triggerbot, no ESP. I removed the triggerbot on purpose, macros only.

**How to use**
1. Run `MacroTool.exe` (needs admin, Windows won't let it send input to the game otherwise)
2. Put your Fortnite keybinds and macro keys in Settings
3. F8 = on/off, Insert = in-game menu

**Antivirus:** it's unsigned and hooks the keyboard, so some antivirus will flag it (Wacatac etc). False positive. Click "Run anyway" or allow it in Defender.

Have fun 💙
